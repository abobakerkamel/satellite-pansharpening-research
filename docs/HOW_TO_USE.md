# How to Use

## PanTiny
Open `examples/PanTiny_Quick_Inference_Colab.ipynb`, upload LR-MS and PAN TIFF files, and Run All.

## HAT
Download the HAT checkpoint from the GitHub Release, open `examples/HAT_Quick_Inference_Colab.ipynb`, upload LR-MS, PAN and the checkpoint, and Run All.

Both examples save a six-band HR-MS GeoTIFF.
